# Simulador de un Kernel
Proyecto final de la asignatura de Sistemas Operativos (rama Ingeniería de Computadores, Grado en Ingeniería Informática). Simulador de un kernel básico programado en C.
## Funcionalidades
Planificación de procesos, carga de programas, gestión de memoria.
## Tecnologías
C
# Instrucciones Compilación:
gcc -Iinclude src/*.c -o simulador -pthread
